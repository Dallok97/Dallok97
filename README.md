# Business Analyst · Business Planning · Project Management

사업의 문제를 정의하고, 데이터를 의사결정 기준과 실행 계획으로 바꿉니다.

사업 현장의 맥락을 이해한 뒤 수요·수익성·성과 데이터를 구조화하고, 이해관계자가 같은 기준으로 선택지를 검토할 수 있게 돕습니다. 필요한 경우 대시보드와 업무 도구를 설계해 분석이 실제 실행으로 이어지게 합니다.

## Focus

- **Business Analysis** — 사업 질문을 정의하고, KPI·비교 기준·분석 구조를 설계합니다.
- **Business Planning & PM** — 수요·수익성·사업 조건을 바탕으로 우선순위와 실행안을 구체화합니다.
- **Data & Workflow Design** — 반복 업무와 의사결정 흐름을 분석해 대시보드·자동화 도구로 연결합니다.

## Selected Work

- **지역 성과 대시보드** — 지역·스쿼드·차종·수요·예약 데이터를 같은 기준으로 비교하는 분석 화면 설계
- **핵심 거점 수요 분석** — 거점별 수요·수익성·차종 성과를 분석해 공급과 인프라 판단 기준 도출
- **신차 지역 배치 시뮬레이터** — 수요와 수익성, 사업 지표를 함께 검토하는 차량 배분 의사결정 도구 설계
- **재배치 효과 검증** — 차량 이동 전후 실적과 시장 흐름을 비교해 유지·회수·추가 이동의 판단 근거 마련
- **할인권 오남용 검수 자동화** — 조회·집계·예외 처리·결과 파일 생성을 하나의 검수 흐름으로 구조화
- **정차 데이터 기반 제휴 기획** — 고객의 정차 패턴에서 수요 신호를 읽고 프로모션 실행안 설계
