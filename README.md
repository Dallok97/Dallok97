## What I do

- **BizOps** — 매출·수요·가동률·공급·제휴 데이터를 바탕으로 운영 의사결정 기준을 만듭니다.
- **Data Analysis** — SQL·BigQuery·Python으로 데이터를 정리하고 KPI와 비교 기준을 설계합니다.
- **AI Product Building** — 대시보드·검수 도구·Slack 자동화·AI Agent를 직접 구현합니다.
